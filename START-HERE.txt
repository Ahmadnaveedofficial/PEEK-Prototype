RUN IN VS CODE
1. Extract the ZIP first.
2. Open the PEEK-folder in VS Code.
3. Select Terminal > New Terminal.
4. Run: npm start
   If Windows PowerShell blocks npm, run: npm.cmd start
5. Open http://localhost:3000 in your browser.

Requires Node.js 22 or later. No npm install or API key is needed.
Stop the server with Ctrl+C. If port 3000 is busy, stop the older server.
You can also use VS Code Live Server on the root index.html.
Do not open public/index.html directly with file://; use an HTTP server.

DATA NOTES
Photos stay in the browser. Uploading starts the curated S23 Ultra reference;
this prototype does not recognize arbitrary devices or call an AI service.
Reference geometry and internal layouts are illustrative, not repair diagrams.
The exterior follows your supplied image; it is not a manufacturer CAD scan.
Performance charts and scores are simulations / samples, not measured tests.
The iPhone 18 record is an unverified concept; Aster, Nimbus and Orbit are
fictional demos. Other imported extended fields may be sample data.
Manufacturer references and dated price listings are linked where available.
Prices, regional variants, carrier support and software availability can vary.
App catalogue search needs internet; local popular suggestions are included.
